# Random ID Generator

Simple random ID generator created as part of my Kodilla Bootcamp.

The package generates a random ID containing letters and numbers.  
You can choose the length of the generated ID.

## Installation

```bash
npm install @kamilmytyl/randomid-generator
```

## Usage

```javascript
const randomID = require('@kamilmytyl/randomid-generator');

console.log(randomID(10));
```

For example, `randomID(10)` generates an ID containing 10 random characters.
